================================================================================
MIDNIGHTTRACKER - INSTALLATION GUIDE
================================================================================

QUICK INSTALL:
1. Copy the entire "MidnightTracker" folder to your WoW AddOns directory
2. Restart WoW or type /reload in-game
3. Look for the minimap icon!

================================================================================

DETAILED INSTALLATION STEPS:

Step 1: Find Your WoW AddOns Folder
------------------------------------
Windows Default Location:
  C:\Program Files (x86)\World of Warcraft\_retail_\Interface\AddOns\

Mac Default Location:
  /Applications/World of Warcraft/_retail_/Interface/AddOns/

If you installed WoW in a custom location, navigate there and look for:
  \Interface\AddOns\


Step 2: Copy MidnightTracker Folder
------------------------------------
Copy the ENTIRE "MidnightTracker" folder (the one containing this file)
into the AddOns directory.

Your structure should look like:
  AddOns\
    MidnightTracker\
      MidnightTracker.toc
      Core.lua
      Data.lua
      Tracker.lua
      Minimap.lua
      Libs\
        (library files)


Step 3: Enable the Addon
-------------------------
At the character selection screen, click the "AddOns" button (bottom left).
Find "MidnightTracker" in the list and make sure it's checked.

If you're playing on Beta/PTR, enable "Load out of date AddOns" as well.


Step 4: Verify It's Working
----------------------------
1. Log into your character
2. Look for a minimap icon (small circular button on your minimap)
3. Hover over it to see your currencies
4. You should see a welcome message in chat: "MidnightTracker v1.0.0 loaded"


TROUBLESHOOTING:
----------------

Problem: Addon doesn't show in the AddOns list
Solution:
  - Make sure the folder is named EXACTLY "MidnightTracker"
  - The .toc file must also be named "MidnightTracker.toc"
  - Folder names are case-sensitive on Mac

Problem: Minimap icon doesn't appear
Solution:
  - Type: /mt show
  - The icon might be hidden behind other minimap icons - try dragging them

Problem: Lua errors appear
Solution:
  - Make sure ALL files are present in the folder
  - Verify that the Libs folder contains all library files
  - Try typing: /reload

Problem: "Interface too old" error
Solution:
  - Enable "Load out of date AddOns" at character select
  - This is common on Beta/PTR versions


FIRST USE:
----------
After installation, type /mt in chat to see available commands:
  /mt show   - Show minimap icon
  /mt hide   - Hide minimap icon
  /mt reset  - Reset icon position
  /mt debug  - Toggle debug mode

Hover over the minimap icon to see all your tracked currencies!


UNINSTALLATION:
---------------
To remove the addon:
1. Exit World of Warcraft completely
2. Delete the "MidnightTracker" folder from your AddOns directory
3. (Optional) Delete saved variables:
   - File: \WTF\Account\<YourAccount>\SavedVariables\MidnightTracker.lua
